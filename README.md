## Предсказание пола человека по записи его голоса при помощи CNN
 ```md
├── PreprocessFeatures.py
├── ModelTraining.py
├── Data
│   ├── test_audio
│   ├── train_audio
│   ├── train_img
│   └── test_img
└── Utils
    ├── min_max_scalers.gz
    ├── std_scalers.gz
    ├── targets.tsv
    ├── train_features.csv
    └── test_features.csv
```
### Исходные данные
В папке `\Data` хранится набор размеченных звуковых записей `\train_audio` в формате `.wav`, используемых для обучения модели. Класс очередной записи хранится в файле `\Utils\targets.tsv`.  
```
                                        \Utils\targets.tsv
                                      ╔═════════════════════╗
\Data\train_audio\sample_name.wav --> ║ sample_name | Label ║
                                      ╚═════════════════════╝
```
В `\Data\test_audio` содержатся неразмеченные звуковые файлы.
### Предобработка данных
Модуль `PreprocessFeatures.py` отвечает за предобработку и формирование используемых признаков.  
- Создаются изображения спектограммы записи, которые подаются на вход CNN. Полученные изображения хранятся в папках `\Data\test_img` и `\Data\train_img`.  
> Для формирования спектограммы используется `librosa.feature.melspectogram` и масштабирование `librosa.power_to_db`
- Расчитывается ряд признаков:
    - `mfcc1-mfcc20` - результат `librosa.feature.mfcc(n_mfcc=20)`, усредненный по времени.
    - `rolloff1-rolloff18` - усредненный по времени результат `librosa.feature.spectral_rolloff(roll_percent=i)` для `i=np.arange(0.05, 0.95, 0.05)`
    - `rms` - усредненный по времени результат `librosa.feature.rms`
    - `centr` - усредненный по времени результат `librosa.feature.spectral_centroid` 
    - `cross_rate` - усредненный по времени результат `librosa.feature.zero_crossing_rate`

Рассчитанные признаки масштабируются и нормализуются. Используемые скейлеры каждого из признаков хранятся в `min_max_scalers.gz` и `std_scalers.gz`.

Предрасчитанные признаки хранятся в файлах `train_features.csv` и `test_features.csv`.

### Используемая модель
Модель состоит из двух частей:
- resnet34 CNN, получающую на вход изображения mel-спектограмм
> Изображения дополнительно приводятся к разрешению (224x224) и нормализуются к 0-ому среднему и 1-ому стандартному отклонению.
- Вектор признаков на выходе CNN объединяется с вектором предрасчитанных для аудиозаписи признаков. Объединенный вектор признаков пропускается через MLP с 1 скрытым и выходным слоем.

Параметры обученной модели хранятся в файле `/Utils/best_model_params.pt`
